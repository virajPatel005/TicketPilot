## Symptoms

You need an application installed that is not already on your device, for
example a statistics package, a browser extension, or a trial-specific
tool. The software may be missing from the standard catalogue, or the
installer may fail with a permissions error.

## Steps to fix

1. Check the software catalogue first; approved apps can be installed
   directly without a ticket.
2. If the app is not listed, submit a request naming the exact software,
   version if known, and the business reason.
3. Do not download installers from the internet or use personal accounts;
   only approved sources are allowed on managed devices.
4. Once IT Support approves the request, follow the install link or the
   deployment notice you receive, and restart if prompted.
5. Confirm the app opens and that your standard documents still load.

## When to escalate

Escalate if the installer fails, if the app is refused for security
reasons, or if you need it urgently for a deadline. Include the error
message and your device name so IT Support can check the deployment logs.
