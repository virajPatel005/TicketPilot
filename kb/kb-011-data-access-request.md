## Symptoms

You cannot open a dataset, a folder, or a report that you need for your
work. The system may say access is denied, show an empty folder, or hide
the item from your list entirely. This is different from a broken report,
where you can open the file but the contents are wrong.

## Steps to fix

1. Confirm you are signed in with the correct work account and role.
2. Check that the data is not simply in a different folder or under a new
   name after a recent reorganisation.
3. Note the exact dataset or report name and the error you see.
4. Submit an access request describing the data, the purpose, and how
   long you need access for.
5. Use only data that has already been shared with you while you wait.

## When to escalate

Escalate to the Data/Apps Team if access is denied, if the data involves
clinical trial subjects, or if a deadline depends on it. Access to trial
data always needs formal approval; do not ask colleagues to share their
credentials or copy data for you.
