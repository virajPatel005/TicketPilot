## Symptoms

You need administrator or elevated access to a system, database, or trial
environment, for example to install drivers, change system settings, or
access restricted clinical trial data. Standard rights are not enough for
the task, and the system blocks the action you need to perform.

## Steps to fix

1. Describe the exact system, the task, and why standard access is not
   enough, including any deadline.
2. Ask your line manager to approve the request in writing first.
3. Submit the request for Security Team review; admin access always needs
   both manager and security approval, with no exceptions.
4. Use the access only for the approved task and the approved time window.
5. Report any incident, mistake, or suspicious activity during the window
   immediately.

## When to escalate

Escalate to the Security Team if approval is delayed and work is blocked,
if a request was denied, or if access is needed outside the approved
window. Never share admin credentials, borrow another person's access, or
work around controls; unapproved admin access is a policy violation.
